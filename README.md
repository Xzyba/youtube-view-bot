# youtube-view-bot
go to your command prompt, type in "pipinstall selenium", highlight it, hit enter and abunch of code should show up, then go to python idle, hit "open" and click the file the bot is in, and the code will show up so put your yt link in, how much views you want, and how long you want each view to be (i recommend 30 seconds because thats how long a watch session takes for a video to get a view) and then click F5 and watch the magic begin
